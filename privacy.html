Privacy Policy

Last updated: September 23, 2026

1. Who we are

Reels Factory ("the application") is a private desktop tool operated by Semen Bezbog ("I", "me") to publish original short videos to my own YouTube channels. Contact: claude999000888@gmail.com.

2. YouTube API Services

The application uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Information obtained through YouTube API Services is also subject to the Google Privacy Policy (http://www.google.com/policies/privacy).

3. What data the application accesses

  • OAuth tokens issued by Google after the channel owner signs in, with the scopes youtube.upload and youtube.readonly.
  • Video IDs and public statistics (views, likes, comment counts) of videos uploaded by the application to the owner's own channels.
  • No other personal information is collected. The application does not access other users' data, contacts, or private messages.

4. How the data is used

OAuth tokens are used only to upload videos to, and read statistics of, the channel owner's own YouTube channels. Statistics are used only to show the owner which of their videos perform better.

5. Storage

All data is stored locally on the owner's computer (token files and a local SQLite database). No data is stored on any server operated by the application. Statistics obtained from YouTube API Services are refreshed regularly and not kept longer than 30 days.

6. Sharing

Data is not sold, shared, or disclosed to any third party. The application does not use cookies, analytics trackers, or advertising.

7. Deleting data and revoking access

  • Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions (security.google.com/settings/security/permissions).
  • Deleting the tokens folder and the local database removes all stored data immediately. On request sent to the contact email, all data will be deleted within 7 days.

8. Changes

Changes to this policy will be posted on this page with an updated date.
